# Celebration audio — optional file overrides

Drop MP3s here to replace the built-in WebAudio synthesis:

- `pop.mp3` — bottle cap pop (~0.5s)
- `jingle.mp3` — short triumphant motif (~1.5s)
- `cheers.mp3` — crowd cheer (~1.5s)

If a file is missing, the game falls back to high-quality synthesis. No errors — just synth.

Recommended source: [pixabay.com/sound-effects](https://pixabay.com/sound-effects/) — free, no attribution required.
