# Celebration audio — optional file overrides

Drop MP3s here to replace the built-in WebAudio synthesis:

- `pop.mp3` — bottle cap pop (~0.5s) — currently synth (no file)
- `jingle.mp3` — short triumphant motif (~1.5s) — currently synth (no file)
- `cheers.mp3` — crowd clapping (~8s) — **real audio, shipped**

If a file is missing, the game falls back to high-quality synthesis. No errors — just synth.

## Attribution

- `cheers.mp3` — derived from [`Clapping hurray.ogg`](https://commons.wikimedia.org/wiki/File:Clapping_hurray.ogg) on Wikimedia Commons. Public domain. Trimmed to 8s, faded out last 1s, loudness-normalised, converted to 96 kbps mono MP3.
